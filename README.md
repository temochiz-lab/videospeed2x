# Video Speed Booster

## この拡張機能について / About This Extension

ボタン一発で再生速度2倍  
Double playback speed with the touch of a button.

ツールバーボタンまたはキーボードショートカットで、動画の再生速度を2倍、1.5倍、1倍の順に切り替えます。同じページ内で次の動画へ切り替わったときや、YouTubeで同じタブに別ページを読み込んだときも、選択した速度を適用します。

Use the toolbar button or press **Alt+Shift+S** to cycle through 2x, 1.5x, and 1x playback speeds. In Firefox, you can change this shortcut in the extension shortcut settings. On YouTube, the selected speed carries over when you navigate to another page in the same tab. On other sites, clicking the toolbar button affects that page.

## 操作

- ツールバーのアイコンをクリック、または **Alt+Shift+S** を押すと、再生速度を **2倍 → 1.5倍 → 1倍** の順に切り替えます。
- アイコンには、次に押したときに適用される速度を表示します。「1.5」は1.5倍、「1」は1倍を表します。
- YouTube のページ移動後も自動適用するため、YouTube へのアクセス権を使います。他のサイトでは、ボタンを押したページの動画だけを操作します。
- Firefox では、about:addons の「拡張機能のショートカット」からキー割り当てを変更できます。

## Firefox アドオン

[Firefox Add-ons のページ](https://addons.mozilla.org/ja/firefox/addon/video-speed-2x/)

## インストール

1. このリポジトリをダウンロードまたはクローンします。
2. ブラウザーの拡張機能管理ページを開きます。
3. 開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選びます。
