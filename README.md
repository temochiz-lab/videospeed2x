# Video Speed Booster

ブラウザーのツールバーから動画の再生速度を切り替える拡張機能です。

## 機能

- ボタンを押すたびに再生速度を **2倍** と **1.5倍** で切り替えます。
- ページ内で新しく読み込まれた動画にも、選択した速度を適用します。YouTube の動画切り替えにも対応します。
- タブごとに速度を管理します。ページを再読み込みすると初期状態に戻ります。

## Firefox アドオン

[Firefox Add-ons のページ](https://addons.mozilla.org/ja/firefox/addon/video-speed-2x/)

## インストール

1. このリポジトリをダウンロードまたはクローンします。
2. ブラウザーの拡張機能管理ページを開きます。
3. 開発者モードを有効にし、「パッケージ化されていない拡張機能を読み込む」からこのフォルダを選びます。
